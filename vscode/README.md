# HisCCS README

HisCCS is an automatic commit message generation tool based on the Blue Heart model, which can help programmers to write high-quality commit messages quickly

## Features

HisCCS can automatically generate commit messages based on the code changes, and the generated commit messages are high-quality and concise, which can help programmers to write commit messages quickly and accurately.

## Extension Settings

This extension contributes the following settings:

* `cmg.apiEndpoint`: the api address.
* `cmg.AccordingHistoryOrNot`: Whether to generate based on history commit messages.
* `cmg.temperature`: the temperature.
* `cmg.max_tokens`: the max tokens.
